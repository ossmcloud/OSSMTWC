The Site Locator

Open Site Locator from the menu. It works like every locator page: map, filters and list.

Filters

GroupFilters
Site LocatorSite Name, Site Type, County, Portfolio (several values can be picked except for Site Name)
Filter by LocationLatitude, Longitude, Radius (Km). You can also double-click the map.
Site ActionsClear Filters

The list

Columns: Site ID, Site Name, Site Type, Address, County, Latitude, Longitude, Portfolio. Click the Site ID or Site Name to open the Site page.

The map

Pins are coloured by portfolio. Click a pin for the site pop-up with the links [Info], [S.A.F.], [S.R.F.], [T.T.] and [Eq.]. See Map pop-ups.

Customers and contractors only see active sites that Towercom has published. Towercom staff see all sites.
The New Site button under Site Actions opens a new Site record in NetSuite in a new tab.

The Site page

The Site page opens from the Site Locator list, from [Info] on the map, or from a Site link in any other list. The browser tab shows the site name.

Users with Edit permission on sites can click Edit to change site details. Everybody else sees the page read-only.

The site panel

The panel on the left also appears on SRF, SAF, Trouble Ticket and equipment pages. Collapse or expand it with the arrow icon; Nexus remembers your choice in this browser.

  • Small map: the site pin, plus a magenta pin for the access point when the site has separate access coordinates.
  • Overview: Site Code, Site Name, Structure (shown as [infra id] type (height m)) and Accommodation.
  • Location: Address, County, Easting, Northing, Latitude, Longitude.
  • Access: Access Easting / Northing, Access Latitude / Longitude, Directions and Access Instructions.

Empty values show as ---.

Read Directions and Access Instructions before every visit. They hold the practical details (gates, keys, tracks) for getting onto the site.

Site page sections

The right side is a set of sections. Click a heading to open or close it.

SectionWhat it shows
SummaryBasic Information (code, name, status, alias, level, type, portfolio, SAF Auto Approve, SAF / SRF status, height above sea level), Site Structures (the site's infrastructure with type, status, ownership, height), Location and Access Track / Safety Info (track type, tenant card required, 4x4 required, parking restrictions, crane / MEWP access, safety and special notes).
EstatesTitle (leasehold and rights of way), Leasehold, Planning and Fibre information.
AssetsStructure details (tower family, anti-climb, fall arrest type, painting dates, locks) and Perimeter (fencing, adjacent ground).
FacilitiesPower (MPRN, meters, phase), Alarms, Air Conditioning and Fire Safety.
FilesDocuments stored against the site. Click a name to preview it. See Files & attachments.
Existing SRFsSpace Requests for this site. Click the SRF ID to open one.
Existing SAFsSite Access requests for this site, with their type, contractor, PICW, status, start / end and the access flags (mast, building, rooftop, crane / cherrypicker, electrical, drone).
Existing Trouble TicketsTickets for this site that you are allowed to see.
EquipmentThe equipment on the site, grouped by TME with its ATME and feeders, plus GIE. Use Hide Inactive (not licenced and not installed) to hide old equipment (on by default). Staff can also filter by Customer. See Site Equipment.
Some sections and fields are only shown to Towercom staff. Customers and contractors only see the structures and files that Towercom has made public.

Starting a request from the Site page

Depending on your permissions, the top bar offers:

  • New SAF: a new Site Access request for this site.
  • New SRF: a new Space Request for this site.
  • New Trouble Ticket: a new Trouble Ticket for this site.

Each opens in a new tab with the site already filled in.
