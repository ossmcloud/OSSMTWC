Logging in

Customers and contractors log in to the Towercom customer centre with the credentials Towercom gave them. Towercom staff use their normal NetSuite login.

Your login must be linked to a profile (your personal record) and your profile to a company. If either link is missing you will see a message such as "Your user is not associated to any profile, please contact TL administrator to set you up." Contact Towercom to get set up.

If you work for more than one company, pick the company you want to act for when you log in. Nexus shows the data of that company only.

Page layout

Every Nexus page has the same bar across the top. From left to right:

  • Status badge: on record pages, a coloured badge with the record number and its current status.
  • Action buttons: buttons for the page, for example New SAF, Submit or Print SDS.
  • Edit / Save / Close: see View mode and edit mode.
  • Menu: the drop-down list of the pages you can open.
  • Gear icon (edit user preferences): theme, font size and grid borders.
  • Read-only icon: shown when you only have view permission on the page.
  • Red exclamation icon: appears only if something went wrong in the page. Click it to see the error and send a report to the support team with email ossm with error report.

The menu

Open the drop-down (it shows -- menu items --) and choose a page. The list only contains the pages your role is allowed to use. The usual entries are:

  • Site Locator
  • Site Equipment (customers and staff)
  • Space Request
  • Site Access
  • Trouble Tickets
  • SDS Files (customers)
  • Company Profile

The exact names come from Towercom's set-up and may differ slightly.

Locator pages and record pages

Most areas of Nexus have two kinds of page.

Locator pages

A locator is a search page with three parts:

  • Map (top left): one pin per site, coloured by portfolio.
  • Filters (top right): filters apply straight away to both the map and the list. Clear Filters resets them.
  • List (below): the matching records. Scroll down and the list grows while the map shrinks; scroll back to the top to restore the map.

Filter by location: enter a Latitude, Longitude and Radius (Km) (5 to 300 km, default 5), or simply double-click the map to search around that point. The map draws a red circle around the area searched.

Map pop-ups: click a pin to see the site name and address and these links. Each opens in a new browser tab:

LinkOpens
[Info]The Site page.
[S.A.F.]A new Site Access request for this site.
[S.R.F.]A new Space Request for this site.
[T.T.]A new Trouble Ticket for this site.
[Eq.]The equipment on this site (view only).

Sites without coordinates are listed but don't appear on the map.

Record pages

Clicking a record in a list (for example an SRF ID) opens its record page in view mode in the same tab. Record pages show the site panel on the left (collapsible with the arrow) and the record on the right.

View mode and edit mode

  • Records open in view mode (read-only).
  • Click Edit to switch to edit mode. The button only appears if your permission allows editing and the record's status allows changes.
  • In edit mode, Save stores your changes and Close returns to view mode without saving.
  • Saving with no changes gives "The record has not changed".
  • If you try to leave a page with unsaved changes, the browser asks you to confirm.

Some pages (Space Request, Site Access, Trouble Ticket) replace Save with their own buttons such as Submit. These are described on each page's help.

Working with tables

  • Click a column heading to sort. Use the column filter pop-up to pick values (select all, unselect all, clear filter).
  • The table toolbar can offer copy into clipboard... and export to csv....
  • Rows with + / - expand to show related rows (for example the ATME and feeders under a TME).
  • The (i) icon next to an equipment number opens Equipment Details, with a search box to find a property.

Your preferences

Click the gear icon to open user preferences:

  • theme: default, dark, mars, forest or ocean
  • font size: small, normal, medium or large
  • grid borders: none, normal, thick or thicker

Changes preview straight away. Click OK to keep them. They are saved against your user, so they follow you on any computer.

Permissions

Towercom gives each role a permission level for each page (feature):

LevelWhat you can do
NoneThe page is not in your menu. Opening it shows "PERMISSION ERROR - You do not have permission to access this feature".
ViewRead only. No Edit button and no "New" buttons.
EditCreate and edit records.
FullCreate, edit, delete and other actions (for example managing company files and profiles).

On top of the permission level, what you can see depends on your company:

  • Customers see their own company's equipment, requests and tickets.
  • Contractors see work for the customers they hold an agent pass for, where the customer has also accepted them as an accredited contractor.
  • Customers and contractors only see sites and structures that Towercom has made public.
  • Towercom staff see everything.

If you think you should see something you can't, contact Towercom.
