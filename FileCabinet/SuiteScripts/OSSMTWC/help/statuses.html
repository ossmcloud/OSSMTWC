Equipment actions

Each line of an SRF creates an equipment action: Install → Licence, Remove → Unlicence, Swap → Swap Unlicence + Swap Licence. Actions are Pending until completed through a SAF. A removal of equipment that was never installed or already removed shows Never Installed / Already Removed.

Companies: Accredited, To Be Renewed, Certs Expired, Pending, Inactive, No.
