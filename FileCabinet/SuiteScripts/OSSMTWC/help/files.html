Use PDF for documents and JPG for photos. These always store and preview correctly. Large files take longer to upload and save.

Uploading a file

The upload dialog asks for:

  • File: pick it from your computer. Without one you get "Please pick a file from your PC".
  • Name (mandatory): filled in from the file name; you can change it.
  • Type (mandatory): the kind of document. The list depends on where you are uploading.
  • Description: optional but helpful.

Revision and status are managed by Towercom. While uploading, keep the pop-up and the browser tab open and don't refresh the page.

Previewing and downloading

  • Click the file name or the preview / download icon. Images, PDFs and videos open in a preview window.
  • Other file types show a "click here to download" link.
  • Ctrl+click opens the file in a new browser tab.
